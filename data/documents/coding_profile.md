# Coding Profile

## Primary Stack
- Python for AI services, data pipelines, and orchestration.
- TypeScript for product surfaces and tooling.
- C++ for robotics, performance-sensitive systems, and lower-level control.

## Frameworks and Tools
- FastAPI, PostgreSQL, SQLAlchemy, Qdrant, Streamlit, Docker, Git, Linux.
- LLM and retrieval work with RAG, embeddings, and local-first assistant workflows.

## Coding Strengths
- Designs systems that are easy to debug, test, and reason about.
- Prefers modular code, explicit interfaces, and predictable behavior.
- Likes solutions that fail clearly instead of silently.

## Coding Habits
- Uses small, verifiable steps.
- Checks the data path, the control flow, and the error path.
- Prefers practical tests and direct validation over speculation.

## Code Review Preferences
- Call out correctness issues, hidden coupling, and weak abstractions.
- Suggest simpler alternatives when they reduce maintenance cost.
- Focus on behavior, not style nitpicks unless style affects clarity.
